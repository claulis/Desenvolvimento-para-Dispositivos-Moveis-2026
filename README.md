## 📖 Introdução

Este repositório reúne o material da disciplina **Desenvolvimento para Dispositivos Móveis**, um curso organizado em 19 aulas que percorre o ciclo completo de concepção de aplicativos móveis: desde as restrições impostas pelo **smartphone como plataforma de projeto** — ciclo de vida, permissões, fragmentação de telas e ergonomia — passando pela **experiência do usuário e a responsividade de interfaces** com base no Material Design, até a **construção de arquiteturas de software reais** com **Flutter** e **React Native**, encerrando com uma análise comparativa de **estilos arquiteturais, modularização e desempenho de renderização**.

Cada aula tem carga horária de 4h e está disponível como um arquivo Markdown individual na pasta [`aulas/`](aulas/).
